# Starbie-Project

A tiny motion-controlled digital pet, basically a desktop Tamagotchi. Fun to have, cool to use.

## Features

- Motion-controlled interaction
- Cute digital pet behavior
- Desktop-friendly gameplay loop
- Simple, playful design

## How to add images

Use Markdown image syntax in your README:

```md
![Starbie-Project preview](./assets/starbie-preview.png)
```

Or use a remote URL:

```md
![Starbie-Project preview](https://example.com/starbie-preview.png)
```
